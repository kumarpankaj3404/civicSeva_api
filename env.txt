# CivicSeva Backend Environment Setup Guide

To get the backend API running on your local machine, you need to create a `.env` file in this directory (civivSeva_api).

1. Copy the `.env.example` file to a new file named `.env`:
   `cp .env.example .env`

2. Generate an application key (if not already done):
   `php artisan key:generate`

3. Update the following crucial variables in your `.env` file:

### 1. Database Configuration
Make sure your local MySQL/MariaDB server is running and you have created a database named `civicseva`.
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=civicseva
DB_USERNAME=root
DB_PASSWORD=your_mysql_password
```

### 2. Mail Configuration (For Help & Support Emails)
To allow the system to send support and confirmation emails, you must use a Google App Password (you cannot use your standard Gmail password).

```env
MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your_email@gmail.com
MAIL_PASSWORD=your_16_digit_app_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=your_email@gmail.com
MAIL_FROM_NAME="${APP_NAME}"
```
**How to get the App Password:**
1. Go to your Google Account Security settings.
2. Enable 2-Step Verification.
3. Search for "App Passwords" and generate a new 16-letter password for "CivicSeva".

### 3. CORS Configuration
Ensure the frontend URL is correct so that React can communicate with this API.
```env
FRONTEND_URL=http://localhost:5173
```

After changing these values, always remember to clear your cache and restart the server:
`php artisan config:clear`
`php artisan serve`
